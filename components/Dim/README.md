화면 전체를 어둡게 깔아 뒤 배경을 가리는 딤(dim) 처리입니다. Figma DDS 파일의 "Dim" 컴포넌트(node-id=2007-23185)를 그대로 옮겼습니다.

지금까지는 Modal 안에만 포함되어 있던 배경 처리였는데, 카카오페이 전자서명 팝업이나 바텀시트처럼 Modal이 아닌 다른 오버레이에도 같은 딤이 쓰이는 걸 Figma에서 확인해서 독립 컴포넌트로 분리했습니다. Modal도 내부적으로 이 컴포넌트와 동일한 스타일(`dds-dim` 클래스)을 공유합니다.

## 소비자가 제공해야 하는 것

- `visible` — 표시 여부. 기본값 `true`. `false`면 아무것도 렌더링하지 않습니다.
- `onClick` — 딤 영역을 클릭했을 때 호출됩니다 (바깥 영역 클릭으로 닫기 등에 씁니다).

## 참고

- 색상은 `#000000` 40% 불투명도(`rgba(0, 0, 0, 0.4)`)로, Figma에 명시된 값 그대로입니다. 별도 토큰이 아니라 이 값 자체가 스펙입니다.
- 화면 전체를 덮도록 `position: fixed; inset: 0`으로 구현했고, 기본 z-index는 900입니다. Modal처럼 그 위에 뜨는 콘텐츠가 있다면 더 높은 z-index를 함께 지정해주세요.
