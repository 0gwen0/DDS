펼치고 접을 수 있는 아코디언입니다. Figma DDS 파일의 "[2.5]Accordion" 문서(node-id=4677-9397)를 그대로 옮겼습니다.

주로 약관/상품 안내처럼 "제목 + 여러 개의 소제목·설명" 묶음을 접어뒀다가 필요할 때만 펼쳐 보여줄 때 씁니다.

## 소비자가 제공해야 하는 것

- `title` (필수) — 접었을 때도 항상 보이는 상단 제목 (예: "상품안내").
- `open` — 펼침 여부. 기본값 `false`.
- `onToggle` — 헤더(제목 + 화살표) 클릭 시 호출됩니다.
- `items` — 펼쳤을 때 보여줄 내용 목록. 각 항목은 `{ title, description }`. `open`이 false면 렌더링되지 않습니다.

## 참고

- 컨테이너는 배경 `neutral-layer`(#F7F7F8), 모서리 `radius-sm`(8px), 안쪽 여백 20px입니다.
- 제목은 16px/700(Bold)/줄간격 22px, 색상 `on-neutral-secondary`(#353542)입니다.
- 펼쳤을 때 각 항목의 소제목은 15px/400/줄간격 23px `on-neutral-tertiary`(#585866), 설명은 14px/400/줄간격 21px `on-neutral-quaternary`(#71717F)입니다.
- 오른쪽 화살표(펼침: 위쪽 화살표, 접힘: 아래쪽 화살표) 아이콘은 원격 자산 URL이 만료되는 SVG라 동일한 형태의 인라인 쉐브론으로 재현했습니다.
- 펼친 콘텐츠 영역은 위쪽 패딩 20px, 아래쪽 패딩 12px이고, 항목 사이 간격은 20px입니다.
