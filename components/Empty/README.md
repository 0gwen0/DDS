리스트나 화면에 표시할 내용이 없을 때 쓰는 빈 상태(empty state)입니다. Figma DDS 파일의 "EmptyPage" 컴포넌트(node-id=376-27456)를 그대로 옮겼습니다.

## 소비자가 제공해야 하는 것

- `message` (필수) — 표시할 안내 문구 (예: "내역이 없습니다", "배당금 내역이 없습니다").

## 참고

- 아이콘 + 문구를 세로로 가운데 정렬한 단순한 구성입니다(아이콘-문구 간격 10px).
- 아이콘은 Figma에서 `icons / light / ic-states-em-darkgrey`라는 이름의 22px 아이콘인데, 원격 자산 URL이 만료되는 SVG인 데다 실제 렌더링된 픽셀이 22px로 너무 작아 세부 형태를 확인하기 어려웠습니다. 그래서 같은 자리(22px, 옅은 색)에 들어가는 범용 "문서 없음" 형태의 인라인 아이콘으로 재현했습니다. 정확한 아이콘이 필요하면 더 큰 원본이나 이름을 알려주시면 다시 가져올게요.
- 문구 색상은 `#808090`, 15px/500(medium)입니다. tokens.json의 기존 컬러 스케일(on-neutral-tertiary #585866, on-neutral-caption #92929E, on-neutral-micro #B0B0B9 등)과 정확히 일치하지 않아 Figma 실측값을 그대로 하드코딩했습니다.
- Figma 문서에는 이 컴포넌트를 실제 화면(배당금 내역 예시)에 배치했을 때의 정렬 가이드도 있었습니다: "빈 공간에서 높이 100% 기준 50%(정중앙)이 아니라 37% 지점 아래에서 정렬"한다는 내용인데, 이건 컴포넌트 자체의 스펙이 아니라 화면 배치 가이드라 컴포넌트에는 반영하지 않았습니다. 실제 화면에 쓸 때 참고하세요.
