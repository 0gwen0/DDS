온보딩·캐러셀 등에서 몇 단계 중 몇 번째인지 보여주는 점(dot) 인디케이터입니다. Storybook(storybook.dndn.io/?path=/docs/indicator--docs)에서 렌더링된 스타일을 그대로 옮겼습니다.

## 소비자가 제공해야 하는 것

- `index` — 현재 활성화된 단계 (0부터 시작).
- `length` — 숫자만 전달하면 점만 표시됩니다. 문자열 배열로 전달하면 점 옆에 현재 index에 해당하는 라벨이 굵게 표시됩니다.

## 참고

- 라벨 스타일(14px, 700)은 기존 타이포그래피 스케일 어디에도 없는 조합이라 `label-md` 스타일을 새로 추가했습니다.
