화면 하단 탭 메뉴입니다. Figma DDS 파일의 "[2.5]BottomNavigation" 문서(node-id=4740-4139)를 그대로 옮겼습니다.

## 소비자가 제공해야 하는 것

- `items` (필수) — 탭 목록. 각 항목은 `{ label, icon? }`. `icon`은 `'home' | 'benefit' | 'invest' | 'lounge' | 'more'` 중 하나이며 생략하면 아이콘 없이 라벨만 표시됩니다. (`benefit`은 아이콘 카탈로그 작업 때 Figma에서 실제로 5개 탭 — 홈/혜택/투자/라운지/더보기 — 이 있는 걸 확인하고 추가했습니다.)
- `selected` — 현재 선택된 탭의 index. 기본값 `0`.
- `onChange(index)` — 탭 클릭 시 호출됩니다.
- `showNotch` — 하단 홈 인디케이터 바(iPhone 노치 기기용 검정 바) 표시 여부. 기본값 `true`.

## 참고

- Figma에는 실제 앱 아이콘 자산(홈/투자/라운지/더보기)이 원격 SVG로 연결되어 있었는데, 홈 탭은 선택 시 브랜드 로고가 박힌 채워진 배지 아이콘으로 바뀌는 등 탭마다 개별적으로 디자인된 자산이라 그대로 재현하기 어려웠습니다. 그래서 `icon` prop에 대해 홈(집)/투자(막대그래프)/라운지(카드)/더보기(가로줄 3개, 실제 "더보기" 선택 아이콘과 동일한 모양)의 범용 인라인 아이콘 4종을 만들어 넣었고, 선택 여부는 다른 탭들과 마찬가지로 색상 변경(진하게/연하게)으로만 표현했습니다. 실제 브랜드 아이콘이 필요하면 개별 아이콘 이름이나 더 큰 원본을 알려주시면 다시 가져올게요 (README 상단의 "아이콘 카탈로그 전체는 아직 반영 안 됨" 이슈의 연장선입니다).
- 각 탭은 동일한 너비(`flex: 1`)로 나눠 가지며, 높이는 50px입니다. 아이콘 24px + 라벨 9px(Regular).
- 선택된 탭은 아이콘·라벨 색상 `on-neutral-primary`(#20202D), 선택되지 않은 탭은 `on-neutral-micro`(#B0B0B9)입니다.
- 상단에 옅은 구분선(1px, `neutral-container` #F4F4F5)이 있습니다.
- `showNotch`가 true면 하단에 34px 높이의 흰 여백과 함께 가운데 검정 홈 인디케이터 바(135×5px, 완전 원형)가 표시됩니다. 실제 iPhone 홈 버튼이 없는 기기의 노치 영역을 흉내 낸 것으로, 웹이나 노치가 없는 화면에서는 `false`로 꺼두면 됩니다.
