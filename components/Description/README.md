캡션 크기의 보조 설명 블록입니다. Figma DDS 파일의 "[2.5]caution" 컴포넌트(node-id=4751-11157, Figma 내부 이름은 "caution"이지만 상단 체크리스트의 "description (=caption)" 항목이 이 패턴입니다)를 그대로 옮겼습니다.

주로 안내/유의사항을 여러 줄의 불릿 리스트로 나열할 때 쓰며, 상단에 "꼭 확인하세요" 같은 제목(아이콘 + 텍스트)을 붙이거나 뗄 수 있습니다.

## title 두 가지

- **title=true (기본값)** — `?` 아이콘 + 제목 텍스트가 리스트 위에 붙습니다.
- **title=false** — 제목 없이 리스트만 표시합니다.

## 소비자가 제공해야 하는 것

- `items` (필수) — 불릿으로 나열할 문자열 배열.
- `title` — 제목 표시 여부. 기본값 `true`.
- `titleText` — 제목 텍스트. 기본값 `'꼭 확인하세요'`.

## 참고

- 제목 텍스트는 15px/600(semibold)/줄간격 21px, 본문은 13px/400/줄간격 20px입니다. 이 조합은 tokens.json의 기존 타이포 스케일(label-sm 13px, body-xs 13px 등)과 정확히 일치하지 않아, Figma에서 실측한 값을 컴포넌트에 직접 넣었습니다. README 상단에 적어둔 "줄 간격 미동기화" 이슈의 연장선입니다.
- 색상은 제목 `on-neutral-tertiary`(#585866), 본문·불릿 `on-neutral-caption`(#92929E)를 씁니다.
- 제목의 `?` 아이콘과 불릿 점은 Figma에서 결과물이 원격 자산 URL(만료됨)로만 내려와서, 동일한 시각 결과를 내는 인라인 도형(테두리 원 + 텍스트, 작은 점)으로 재현했습니다. 정확한 벡터 파일이 필요하면 알려주시면 다시 받아올게요.
