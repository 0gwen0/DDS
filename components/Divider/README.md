화면 안에서 영역을 구분하는 구분선입니다. Figma DDS 파일에서는 컴포넌트 레이어 이름이 "[2.5]Chip"으로 잘못 붙어 있지만(궨 확인), 실제로는 Divider 문서 페이지(node-id=4744-5390)에 있는 두 종류의 구분선입니다.

## thickness 두 가지

- **thin (기본값, "H1")** — 1px 얇은 선. 텍스트/리스트 사이처럼 같은 섹션 안에서 항목을 나눌 때 씁니다. 색상 `neutral-container`(#F4F4F5).
- **thick ("H10")** — 10px 두꺼운 띠. 화면을 완전히 다른 섹션으로 나눌 때 씁니다. 색상 `neutral-layer`(#F7F7F8). Figma 예시에서는 화면 좌우 끝까지 꽉 차는(full-bleed) 형태로 쓰입니다 — 좌우 패딩이 있는 컨테이너 안에서 쓸 때는 음수 마진 등으로 바깥까지 채워주세요.

## 소비자가 제공해야 하는 것

- `thickness` — `'thin'`(기본값) 또는 `'thick'`.
